MVP for CALC-College

# Product Name

## CALC College

A lightweight student utility platform for:
- Polytechnic students
- Engineering students
- College students

---

# MVP Goal

Build a:
- fast
- both mobile and desktop
- single-page
- dark retro UI

web app using:
- HTML
- CSS
- JavaScript

The MVP should solve daily student problems immediately.


# MVP ESSENTIAL FEATURES

## 1. Attendance Calculator
### Purpose
Helps students track attendance percentage.

### Inputs
- Total classes
- Attended classes

### Output
- Attendance %
- Classes needed for 75%

---

## 2. Internal Mark Predictor
### Purpose
Predict internal marks before exams.

### Inputs
- Assignment marks
- Series exam marks
- Attendance score

### Output
- Predicted internal mark

---

## 3. CGPA Calculator
### Purpose
Calculate GPA/CGPA quickly.

### Inputs
- Grade points
- Credits

### Output
- GPA/CGPA

---

## 4. Exam Countdown
### Purpose
Shows remaining days for semester exam.

### Inputs
- Exam date

### Output

```text
like "12 days remaining"
```

---

# FUNCTIONAL LOGIC

# Attendance Calculator Logic

## Formula

```js
attendance = (attended / total) * 100;
```

---

## Required Classes Formula

```js
needed =
((0.75 * total) - attended) / 0.25;
```

---

# Internal Mark Predictor Logic

## Example Formula

```js
internal =
(assignments * 0.2) +
(series * 0.7) +
(attendance * 0.1);
```

---

# CGPA Logic

```js
cgpa =
totalGradePoints / totalCredits;
```

---

# Countdown Logic

```js
daysLeft =
(examDate - today) / (1000*60*60*24);
```
