# CALC
-Which is for college students. It is a simple and easy to use web app that helps students to calculate their CGPA, Attendance, etc.

# CALA-College

A lightweight student utility platform for:
- Polytechnic students
- Engineering students
- College students

# Story 
When I get my mark result, And teacher tell me calculate my CGPA, and Grade and i don't know how it calculate it.
I searched on google, after searching a few min, finaly I find a CGPA calculater.
But it has only one function on it(To calculate the CGPA).
And I was obsessed with How can I make this kind of web with more features.
That way I was drive into making this website.

Build a:
- fast
- both mobile and desktop
- single-page
Webapp using:
- HTML
- CSS
- JavaScript

# ESSENTIAL FEATURES

# 1. Attendance Calculator
# Purpose
Helps students track attendance percentage.

# Inputs
- Total classes
- Attended classes

# Output
- Attendance %
- Classes needed for 75%

# 2. Internal Mark Predictor
# Purpose
Predict internal marks before exams.

# Inputs
- Assignment marks
- Series exam marks
- Attendance score

# Output
- Predicted internal mark

# 3. CGPA Calculator
# Purpose
Calculate GPA/CGPA quickly.

# Inputs
- Grade points
- Credits

# Output
- GPA/CGPA

# 4. Exam Countdown
# Purpose
Shows remaining days for semester exam.

# Inputs
- Exam date

# Output

text:
like "8 days remaining"

# How to Setup and Run the Project:
- First download the project repo as a zip file and extract it.
- Open the extracted folder and find the `main.html` file.
- Double-click on `main.html` to open it in your default web   browser.
- You should now see the CALC-College web app running locally on your machine.
- And you can also do it in your mobile phone by opening the `main.html` file in your mobile browser.
